# 观象 - 今日运势

一个无需后端的传统文化娱乐向今日运势页面。填写姓名、出生日期和生肖后，页面会结合当天日期生成一份专属的五行气象、时运和行动提示。

> 本项目内容仅供传统文化娱乐与自我觉察参考，不构成任何现实建议或预测。

## 功能

- 姓名、出生日期、生肖信息录入
- 根据出生年份自动推荐生肖，也支持手动切换
- 每日稳定生成运势指数、五行气象与时运窗口
- 提供今日断语、行动指引与“再求一签”交互
- 响应式设计，适合手机和桌面浏览

## 使用

本项目是纯静态网页，无需安装依赖。

直接用浏览器打开 `index.html`，或在本地启动静态服务器：

```powershell
python -m http.server 4173
```

然后访问 `http://127.0.0.1:4173`。

## 文件说明

```text
index.html  页面结构
style.css   视觉样式与响应式布局
app.js      表单交互与运势内容生成逻辑
```

## 部署

GitHub Pages 部署时，选择 `main` 分支和 `/(root)` 目录即可。

部署完成后的地址格式：

```text
https://<GitHub 用户名>.github.io/guanxiang-fortune/
```
